Generate a short video with the user's configured video model. It is asynchronous and can take several minutes, sometimes much longer: submit, wait, then download. The result gives a workspace path under /workspace/out/video/ and, when the current model can see images, a poster frame. Only use it when the user explicitly asks for a video; each generation costs money. First-frame images must be workspace paths; with a first frame some models keep the image's aspect ratio instead of the one you pass. If the service refuses the content, the task fails or the submit is unconfirmed, report the reason and do not retry automatically. Do not claim you watched or heard the result; the poster is only one frame.
